Entry for the [One Letter for Your Day](https://make.fun/competitions/u-puan-one-letter-for-your-day-e54e9c36) bounty on make.fun.

## What it does

`main.ts` writes exactly one letter, A to Z, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
That single letter is the whole entry — behind it sits the word that describes
Luna's day: a Jakarta night shift spent building bounty after bounty, still
going when the sun comes up.

Deterministic, standard library only, no network, no secrets. Run it with
Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

- `main.ts` — the entry program
